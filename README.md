## 🚀 Como usar

### 1. Local
Basta abrir o `index.html` no navegador ou:

```bash
npx serve .
```

### 2. Hospedagem (Hostinger / Vercel / Netlify)

Faça upload de todos os arquivos para a pasta `public_html` ou arraste o ZIP no painel.

Não precisa build — é vanilla.

### 3. Configurar WhatsApp e contatos

Edite no `index.html`:

```html
<!-- Troque o número -->
<a href="https://wa.me/5553997073648">...</a>

<!-- Troque o e-mail -->
<strong>otavio@dev.local</strong>
```

No `css/style.css` você pode alterar as cores no `:root`:

```css
:root{
  --bg:#080808;
  --accent:#C6FF00;
}
```
